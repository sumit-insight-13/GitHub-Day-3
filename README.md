# Terraform Training Repository

## Overview

This repository contains hands-on exercises, assignments, and examples completed during Terraform training.

## Training Objectives

- Learn Terraform fundamentals and best practices
- Understand Infrastructure as Code (IaC)
- Deploy resources on Azure
- Manage Terraform state files
- Implement GitHub Actions CI/CD workflows

## Repository Structure

| Folder | Description |
|----------|-------------|
| Day-1 | Terraform Basics |
| Day-2 | State Management |
| Day-3 | GitHub Workflow |
| Day-4 | Azure Deployments |
| Day-5 | Final Project |

## Prerequisites

Before using this repository make sure:

- Terraform installed
- Azure CLI installed
- Git installed
- GitHub account configured
